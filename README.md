# Professional Experience Static Website
Thanks for visiting!

This repository contains the source code for a static website showcasing my professional experience located at [https://work.kubeklepsch.com/](https://work.kubeklepsch.com/).

## Description

This project is a simple, static website designed to present my resume and experience. It is built with simple HTML/CSS that is hosted on a custom domain via Github Pages and updated automatically via the automatically generated Github Actions workflow.

The original plan was to follow the [Cloud Resume Challenge](https://cloudresumechallenge.dev/) on Microsoft Azure, however I decided to cut costs by utilizing Github Pages for free for now.
